Photo & PDF Tools

Photo resize, 2-photo merge aur PDF page size adjust karne ke tools.

Photo resize

Passport photo requirements authority ke hisaab se vary kar sakte hain. Required crop, background aur dimensions pehle check karein.

Photo merge

Yeh basic merge tool hai; face ko automatically alter nahi karta.

PDF page resize

PDF resize ke liye browser mein PDF library load hoti hai. File kisi server par upload nahi ki jaati. Result ko print karne se pehle verify karein.

PVC card print preset

Standard CR80 / ID-1 PVC card ka nominal size 85.60 × 53.98 mm hota hai. Har scheme/card ka design, crop aur legal issuance rules alag ho sakte hain.

Printer dialog mein 100% / Actual size select karein. Printer margins, scaling aur lamination pouch ki wajah se size badal sakta hai. Pehle test print aur ruler se measurement karein. Official card ko recreate/alter karke misleading document na banayein.
